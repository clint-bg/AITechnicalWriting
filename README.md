# T4L-AITechnicalWriting
Reveal js presentation on AI Supported Technical Writing

The python code used to generate templated initial drafts of feedback of student writing is in the "TemplatedFeedback.ipynb" file. It will cycle through all of the reports in a given directory and generate a feedback document for each report. The feedback document is saved in the same directory as the report with a ".html" extension. That html file can be opened in a web browser and printed to a pdf.
